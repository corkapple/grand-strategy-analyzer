# Install the app

Pick your computer. You only do this once.

First, go to the **[Releases page](../../../releases/latest)** and look under **Assets** at the bottom.

## Windows

1. Download **`Grand.Strategy.Analyzer_…_x64-setup.exe`**.
2. Double-click it.
3. Windows may show a blue box, **"Windows protected your PC"**. This appears because the app is new and not
   signed by a big company. It is normal.
   Click **More info**, then **Run anyway**.
4. Follow the installer. Open **Grand Strategy Analyzer** from the Start menu.

## Mac

You need to know which kind of Mac you have: click the Apple menu, then **About This Mac**.
- Says **Apple M1, M2, M3…** (Apple chip): download **`…_aarch64.dmg`**.
- Says **Intel**: download **`…_x64.dmg`**.

1. Double-click the downloaded `.dmg` file.
2. A window opens. **Drag the app onto the Applications folder** in that window. (Don't run it from the window.)
3. Open your **Applications** folder. **Right-click** (or Control-click) **Grand Strategy Analyzer** and choose **Open**.
4. A warning says Apple could not verify the app. Click **Open** (or **Done**, then see the next step).
5. If there is no Open button: open **System Settings → Privacy & Security**, scroll down, click **Open Anyway** next to
   the app, and confirm with your password or Touch ID.

You only do this the first time. After that, open it like any other app.

> **Why the warnings?** Apple and Microsoft charge yearly fees to remove them. The app is safe to use, and its
> full source code is in this repository.

## Updating

Versions from **0.1.16** update themselves. When a new version is ready, a green bar appears at the top of the app:
**"Version X is available. Install and restart."** Click it. The app downloads the update, checks that it is genuine, installs it
and restarts, and your history and settings are kept. You can also check by hand in **Settings → Check for updates**, or
turn the automatic check off there. Updates need no new warnings, because the app installs them itself.

If you have an older version, install the newest one from the Releases page once. It updates itself from then on.
